# Princess Tale builds

Android builds of Princess Tale (Morialkar build), published as GitHub releases.

**Download:** open the [Releases page](../../releases) and take `PrincessTale-<version>.apk`.
The `.sha256` file next to it holds the checksum of the APK.

- Android 7 or newer, ARM64 devices only.
- Install each version over the previous one, without uninstalling, to keep your account.
